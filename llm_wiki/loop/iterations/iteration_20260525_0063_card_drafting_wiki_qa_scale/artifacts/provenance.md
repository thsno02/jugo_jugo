# 出处论证：小规模研究 wiki 可用于复杂问答

## 事实来源

这张卡只使用 `data/raw/webpage/karpathy-x-launch-post/raw.json` 的 JSON pointer `$.tweet.quote.text`。候选字段仅用于核对当前任务指定的候选 11，没有使用其它候选或相邻内容。

## 支撑关系

该 quote text 的 `Q&A` 段落明说：当 wiki 足够大时，示例中的近期研究 wiki 规模为约 100 篇文章、约 400K words；在这个规模下，可以让 LLM agent 针对该 wiki 提出各种复杂问题，并让 agent 去研究答案。段落还把这种规模称作小规模，并说明 LLM 在自动维护索引、简短摘要和读取重要相关资料方面已经相当可用。

因此，卡片的核心事实可以被该字段直接支撑：一个约 100 篇文章、约 400K words 的近期研究 wiki，已被描述为可供 LLM agent 做复杂 Q&A 与继续研究。

## 整理后的表述

卡片把来源中的英文叙述整理为中文原子事实，并保留必要限定：

- “某个近期研究 wiki”对应来源中的近期研究 wiki 示例。
- “约 100 篇文章、约 400K words”对应来源给出的规模。
- “针对该 wiki 回答各种复杂问题，并继续研究答案”对应来源中 Q&A 段落对使用方式的描述。
- “小规模”只按来源对该规模的描述使用，不推导为通用阈值。

## 成立范围

该事实只成立于被引用推文的 quote text 所描述的情形：一个具体的近期研究 wiki，在约 100 篇文章、约 400K words 的量级上，用 LLM agent 做围绕 wiki 的复杂问答和答案研究。它不说明其它 wiki 一定达到同样效果，也不说明具体模型、工具链、作者身份或发布时间。

## 为什么保持 draft

当前证据来自单一 JSON 字段中的 quote text，能够支撑“被引用推文如此描述”这一事实，但没有额外来源用于交叉验证实际效果、复现实验条件或上下文细节。因此知识卡保持 `status: draft`。
