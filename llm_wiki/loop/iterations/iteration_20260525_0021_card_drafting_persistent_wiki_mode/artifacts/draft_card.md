# 持久 wiki 替代模式

statement: 该来源提出的替代模式是让 LLM 递增式构建并维护一个持久 wiki，使其位于用户与原始来源之间，并在新增来源时把关键信息整合进既有 wiki。

fact_type: known_fact

support: 指定证据段落把这种模式明确区别于“查询时从原始文档检索”，并说明 LLM 会维护一个位于用户与原始来源之间的持久 wiki；新增来源加入时，LLM 会读取来源、抽取关键信息，并整合进既有 wiki。

scope: 仅限该来源提出的 LLM Wiki 模式。

status: draft

这张卡只记录该来源提出的一种工作模式：wiki 不是临时查询结果，而是一个会随来源增加而持续更新、累积综合结果的中间知识制品。
