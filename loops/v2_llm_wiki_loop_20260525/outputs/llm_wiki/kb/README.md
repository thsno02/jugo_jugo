# LLM Wiki 知识库产物面

这里放最终要交付的人类可读知识库，而不是循环控制文件。

当前阶段的目标是从 `data/` 中已有来源生长原子事实知识卡。知识库从 0 到 1 的顺序是：

```text
事实候选 -> 草稿知识卡 -> 出处论证 -> 审计通过 -> 已采纳知识卡
```

## 当前目录约定

- `candidates/`：来源挖掘后得到的事实候选。
- `cards/`：zet 风格原子事实知识卡。
- `provenance/`：每张知识卡对应的出处论证。
- `indexes/`：最小索引和采纳状态。

这些目录可以在第一轮实际产出时创建。不要为了看起来完整而提前制造空卡、空索引或主题骨架。

## 当前非目标

- 不做枢纽页。
- 不做聚类。
- 不追求主题覆盖。
- 不把 agent 综合当作事实来源。
