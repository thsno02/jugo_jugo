## 支撑关系

来源正文直接解释 `idea file` 的理念：在 LLM agents 时代，分享具体代码或应用的必要性下降；发布者可以分享想法，由接收者的 agent 按具体需求定制并构建。这足以支撑卡片中的 statement、fact_type、support 和 scope。

## 来源明说

来源明说的内容包括：`idea file` 是发布者想分享的改进版本形式；其理念与 LLM agents 时代有关；重点是分享 idea，而不是具体 code/app；另一个人的 agent 可以据此进行 customizes 与 builds。

## 整理表述

卡片把英文帖文压缩成中文原子事实，并把 “less of a point/need” 整理为“必要性降低”，把 “other person's agent customizes & builds it for your specific needs” 整理为“接收者的 agent 可以按其具体需求定制并构建”。这些是语义整理，不新增外部背景。

## 成立范围

该事实只在这条发布帖对 `idea file` 概念的表述范围内成立。它不声称 `idea file` 是通用行业定义，也不声称该理念已经被其它来源确认。
