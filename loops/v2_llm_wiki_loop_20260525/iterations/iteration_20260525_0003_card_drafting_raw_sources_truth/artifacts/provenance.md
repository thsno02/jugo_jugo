# 出处论证：Raw sources 是只读事实来源

## 事实来源

这张草稿卡来自 `data/raw/gist_raw/karpathy-gist-llm-wiki/raw.txt:27-30`。任务包指定的候选 8 也把同一行段列为证据。

## 支撑关系

来源在介绍三层架构时专门定义了 `Raw sources` 层。第 29-30 行说明这一层是用户策展的来源文档集合，并列举文章、论文、图像和数据文件等材料；同一段还说明这些材料不可变，LLM 会读取它们但不会修改它们，并把这一层称为 `source of truth`。

因此，草稿卡中的主要事实可以被该来源直接支撑：`Raw sources` 是用户策展的来源集合；它在该架构中是不可变、只读、作为事实依据的一层。

## 明说与整理

来源明说的部分包括：`Raw sources` 是用户策展的来源文档集合；这些材料是不可变的；LLM 从中读取但不修改；这一层是 `source of truth`。

整理后的部分包括：把 `Raw sources` 表述为“原始来源”，把 `source of truth` 表述为“事实来源”，并把“LLM reads from them but never modifies them”整理为“由 LLM 读取但不修改”。这些整理没有加入额外背景，只是把来源原句压缩成中文事实表述。

## 成立范围

该事实只在该来源描述的架构内成立，且只限于 `Raw sources` 层。它不说明其它知识库、其它 LLM 系统或其它层级是否也应采用同样规则。
