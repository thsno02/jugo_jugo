## 源证据

- main.tex 行 106：「In Zep, memory is powered by a temporally-aware dynamic knowledge graph $\mathcal{G}=(\mathcal{N}, \mathcal{E}, \phi)$ ... This graph comprises three hierarchical tiers of subgraphs: an episode subgraph, a semantic entity subgraph, and a community subgraph.」
- main.tex 行 108–110：三层子图各自的节点/边的形式化定义（episodic, semantic entity, community）。
- main.tex 行 113：「These models distinguish between episodic memory, which represents distinct events, and semantic memory, which captures associations between concepts and their meanings」——给出心理学类比的来源（gonzalez 引用）。
- main.tex 行 135：「the same fact can be extracted multiple times between different entities, enabling Graphiti to model complex multi-entity facts through an implementation of hyper-edges.」
- main.tex 行 149：「we employ a label propagation algorithm rather than the Leiden algorithm. This choice was influenced by label propagation's straightforward dynamic extension」。
- main.tex 行 151：「the resulting communities gradually diverge from those that would be generated by a complete label propagation run. Therefore, periodic community refreshes remain necessary.」

## 卡片范围是否成立

本卡只覆盖"Zep/Graphiti 的图结构本身（三层、为什么这么分、增量与刷新的代价）"这一独立主题。bi-temporal 边失效、检索/重排细节、benchmark 结果会拆到其他卡。所有主张均能在 §2 找到逐字依据；"对应人类记忆心理学"是论文自己的论证（行 113，引 gonzalez），不是引申。"周期性刷新必要"也来自原文行 151。
