## 为什么提取此卡片

源文档提供了一条 2015-2022 年的时间线，列出了 7+ 家大型组织在 Write the Docs 会议上报告 docs-as-code 实施经验的具体记录。这构成了一个独立的经验模式（empirical pattern）：docs-as-code 从科技先行者到公共部门/云巨头的扩散轨迹。

## 与现有卡片的区分

- `docs-as-code`：描述理念本身（五大工具支柱 + 哲学定位），仅在 footnote 中提及"被广泛实践"
- `documentation-merge-gate`：聚焦单一激励机制
- `documentation-shared-ownership`：聚焦文化转变

本卡片聚焦的是**经验证据层**：哪些组织、在什么时间、报告了什么级别的采纳，以及这些数据点所揭示的扩散阶段规律。这是一个独立的 Zettel，因为"理念是什么"与"理念如何在现实中扩散"是不同层次的知识。

## 信息密度评估

源文档对每个案例仅给出一句话描述（会议演讲记录），但 7 个数据点组合在一起形成了可分析的结构化时间线，这种结构化信息值得独立成卡。
