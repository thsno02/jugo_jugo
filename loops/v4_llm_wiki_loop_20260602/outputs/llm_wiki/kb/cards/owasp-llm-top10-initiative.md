OWASP Top 10 for Large Language Model Applications 是一项始于 2023 年的社区驱动安全倡议，旨在识别和应对 AI 应用特有的安全问题 [^src-1]。该倡议的背景是 LLM 技术已广泛渗透至各行业和应用场景，相关安全风险也随之扩大。随着 LLM 被更深入地嵌入客户交互和内部运营等场景，开发者和安全专业人员正在不断发现新的漏洞类型及其应对方法 [^src-2]。

OWASP 于 2025 年进一步发布了 Agentic AI Top 10，将 LLM 安全关注延伸到能够自主规划和行动的 agent 系统 [^card-1]。
