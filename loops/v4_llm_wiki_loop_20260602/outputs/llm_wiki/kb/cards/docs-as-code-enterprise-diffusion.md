Write the Docs 会议记录了 docs-as-code 理念从 2015 年到 2022 年在大型企业中的扩散轨迹，构成了一条清晰的采纳时间线[^src-1]。

| 年份 | 组织 | 关键信号 |
|------|------|----------|
| 2015 | Google | Riona MacNamara 报告 docs-as-code"完全改变了 Google 的文档方式"[^src-2] |
| 2016 | Rackspace, Microsoft, Balsamiq, Twitter | 四家公司组成面板讨论各自的采纳实践[^src-3] |
| 2016 | Rackspace, Capital One | Margaret Eker & Jennifer Roundeau 给出 docs-as-code 概述[^src-4] |
| 2017 | F5 | Jodie Putrino 分享 docs-like-code 实战经验[^src-5] |
| 2019 | UK Government Digital Service | Jen Lambourne 分享英国政府数字服务的采纳经验[^src-6] |
| 2020 | platformOS | Diana Lakatos 展示基于 GitHub 的全远程社区贡献编辑工作流[^src-7] |
| 2022 | Amazon Web Services (AWS) | Marcia Riefer Johnston & Dave May 复盘团队迁移：成功、失败与下一步[^src-8] |

这一时间线揭示了几个扩散规律：

1. **先行者阶段**（2015-2016）：科技巨头（Google、Microsoft、Twitter）率先采纳并公开布道
2. **实践深化阶段**（2017-2019）：中型企业（F5）与公共部门（UK GDS）开始报告具体实施细节
3. **主流化阶段**（2020-2022）：开源社区（platformOS）与云巨头（AWS）将方法论与远程协作/大规模迁移结合

该扩散模式印证了源文档的总结判断："Docs as Code 概念在软件行业已被广泛实践，并正在写作社区中获得更多采纳"[^src-9]。
