GraphRAG 强烈建议在正式索引前运行自动提示词调优（`graphrag prompt-tune`），因为默认提示词针对通用场景设计，可能无法在特定领域数据上取得最佳效果 [^src-1]。

**调优流程** [^src-2]：
1. 加载输入数据并按 `--chunk-size`（默认 200 tokens）切分为 text units
2. 使用文档选择方法从 text units 中采样代表性子集
3. 对样本执行一系列 LLM 推断与模板替换
4. 输出领域适配的提示词文件到 `prompts/` 目录

**文档选择方法**（`--selection-method`）[^src-3]：
- `random`（默认推荐）：随机选择 text units
- `top`：取前 n 个 text units
- `all`：使用全部 text units（仅限小数据集）
- `auto`：将 text units 嵌入低维空间，选择距质心最近的 k 个邻居——适合大数据集需要代表性样本的场景

**关键参数**：
- `--domain`：指定领域（如 "space science"），为空则自动从输入推断
- `--language`：输入处理语言，如与输入不同则 LLM 会翻译
- `--discover-entity-types`：允许 LLM 自动发现实体类型（推荐用于主题多样的数据）
- `--min-examples-required`：实体提取提示词所需的最少示例数（默认 2）

**生成的提示词** 需在 `settings.yaml` 中配置引用 [^src-4]：
```yaml
extract_graph:
  prompt: "prompts/extract_graph.txt"
summarize_descriptions:
  prompt: "prompts/summarize_descriptions.txt"
community_reports:
  prompt: "prompts/community_report.txt"
```

提示词支持手动调优——每个模板使用 `{token_name}` 占位符，如 `{input_text}`、`{entity_types}`、`{tuple_delimiter}` 等，用户可在理解替换规则后深度定制 [^src-5]。
