OWASP Top 10 for Large Language Model Applications 项目于 2023 年启动，是一项社区驱动的安全工作，目标是识别、突出并应对 AI 应用（尤其是大语言模型应用）特有的安全问题。[^src-1]

随着 LLM 技术持续向各行业和应用场景扩展——从客户交互到内部运营——相关安全风险也同步增长。开发者和安全专业人员正在持续发现新的漏洞类型，同时也在开发相应的防御与对策。[^src-1]

该项目以规范性标准的形式发布年度更新（2023/24 版、2025 版），为行业提供 LLM 安全风险的优先级排序参考。

[^src-1]: `data/raw/webpage/owasp-llm-top10-2025/markdown.md` -- "About" P1 -- "The OWASP Top 10 for Large Language Model Applications started in 2023 as a community-driven effort to highlight and address security issues specific to AI applications."
