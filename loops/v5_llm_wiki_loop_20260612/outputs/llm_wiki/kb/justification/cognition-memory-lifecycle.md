# Justification: cognition-memory-lifecycle

## 为什么产出此卡
材料在 "Read the science" 一节明确列出四阶段模型（Evidence → Consolidation → Decay → Teaching），这是产品的理论框架/机制描述，与前一张卡的操作工作流（Ask-Capture-Save-Retrieve）构成不同抽象层次，值得独立成卡。

## Evidence basis 选择
选择 `practitioner_report`：虽然材料暗示有科学基础（"Read the science"），但页面本身未引用具体论文，仅为产品团队对其设计机制的描述。

## 原子性判断
四阶段构成完整生命周期模型，各阶段相互依赖（Evidence 是 Consolidation 的输入，Decay 作用于 Consolidation 产物，Teaching 是最终输出），作为整体保留。

## Hedge 使用
材料未使用 hedge 语言，但卡片在 person-specific retrieval 部分使用"据材料描述"标明信息来源限制。
