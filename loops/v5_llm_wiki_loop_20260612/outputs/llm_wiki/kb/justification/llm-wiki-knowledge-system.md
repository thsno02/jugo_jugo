# Justification: llm-wiki-knowledge-system

## 为什么提取这张卡

LLM wiki 的核心定义和架构是该仓库 README 的中心概念。材料明确定义了 LLM wiki 是什么（"a knowledge system where the LLM maintains structured wiki pages"），给出了完整的目录结构（raw/ + wiki/ + index.md + log.md），并阐述了复合增长机制（"compound over time"）。

## Evidence basis 选择: code_implementation

该仓库是一个实际的代码实现项目（有 npm install 命令、具体的目录结构、工具兼容性矩阵），而非纯理论讨论。README 中描述的架构直接反映了代码实现的结构。

## 原子性判断

该卡聚焦于"LLM wiki 是什么"这一单一概念，包含定义+架构+增长机制，均属同一原子主题。与 RAG 对比和 skill 实现细节分别拆入其他卡。
