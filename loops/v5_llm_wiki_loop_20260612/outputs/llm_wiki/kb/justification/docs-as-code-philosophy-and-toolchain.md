## 原子性判断
本卡聚焦"是什么"（定义 + 工具链 + 文化目标），与"带来什么好处"（benefits 卡）分离。

## Evidence basis 选择
取值 `documentation`：材料为社区官方文档页面，内容为规范性定义。

## 摘要设计
summary 包含 canonical concept、所有 aliases、五个工具名称、核心论断关键词，便于 grep 命中。
