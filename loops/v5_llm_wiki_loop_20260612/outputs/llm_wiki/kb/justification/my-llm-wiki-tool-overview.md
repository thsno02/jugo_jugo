# Justification: my-llm-wiki-tool-overview

## 为什么产出此卡
my-llm-wiki 是材料的主体对象——一个具体的开源工具。其技术栈、能力范围、使用方式构成一个完整的原子知识单元。

## 证据强度
- evidence_basis = documentation：材料为 PyPI 官方包页面，属于一手项目文档
- 技术细节（Tree-sitter 支持语言列表、Docling pipeline、输出格式）直接来自项目 README

## 边界决策
- 概念来源（Karpathy 三层架构）独立成卡，此卡通过 cross-link 引用
- write-back 机制作为独立机制单独成卡
- 项目元数据（版本、作者、许可）包含在此卡中，因其不足以单独成卡
