## Justification: agent-environment-awareness-under-stress

**为什么产出此卡**: Agent 对环境异常的自我诊断能力是一个独立研究维度，既关乎鲁棒性也关乎可解释性。GPT-5.2 "意识高但仍被攻击"的矛盾现象有独立知识价值。

**Reframing 决策**:
- 独立于 Chaos Monkey 卡（那张讲工具，本张讲 Agent 的反应）
- 包含高/低置信度区分的方法学细节
- 与 model-capability-security-disconnect 交叉引用
