# Justification: connections-as-value

## Extraction rationale
这是材料的认识论基础——为什么 cross-references 和 interlinks 如此重要。与 Memex 的历史关联提供了思想谱系。独立于操作层面的卡片。

## Evidence quality
- 明确引用 Bush (1945) 作为思想来源
- "related in spirit" 是轻度 hedge——不声称直接继承，而是精神相关
- 对 web 的批判性对比增强了论证

## Atomicity check
仅覆盖连接价值的认识论主张及其 Memex 渊源。不涉及具体如何实现连接维护（那是 lint/ingest 的范畴）。
