# Justification: locomo-human-machine-pipeline

## 抽取理由
Human-machine pipeline 是 LoCoMo 论文的方法论核心贡献之一——它展示了一种平衡规模与质量的合成数据生成范式。已有卡分别覆盖了 pipeline 的子组件（reflect-and-respond-agent, temporal-event-graph-dialogue），但缺乏将四阶段作为整体方法论描述的卡片。

## 原子性检验
该卡聚焦于"四阶段管线的整体设计"这一方法论概念，不深入任何单一组件的内部工作原理（各有专卡）。它的知识价值在于展示了各组件如何编排以及人工验证阶段的角色。
