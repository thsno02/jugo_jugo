# Justification: openkb-skill-factory

## 为什么产出此卡
Skill Factory 是材料中篇幅最大的单一功能模块（独立 H3 节 + 详细子节），代表 OpenKB 从"知识库工具"向"agent 技能生产平台"的延伸。作为独立 generator 且具备完整质量保障体系，构成独立原子概念。

## Evidence basis 选择
`code_implementation`：README 列出完整 CLI 命令（skill new/validate/eval/history/rollback）并描述产出文件结构，属于已实现功能。

## 拆卡决策
从双层架构卡中拆出：双层架构卡描述整体组织，本卡深入 Skill Factory 这一特定 generator 的机制、产出、质量保障和分发方式。
