# Justification: context-window-degradation-limits

## 为什么产出此卡
context 退化是 LLM Wiki 存在价值的底层技术前提之一，讨论中有明确的数字引用（200K-300K）和逻辑反驳链。

## 证据强度
- 数字（200K-300K 退化点）来自社区经验观察，非论文引用
- 是广泛认知的现象但具体数字因模型/任务而异
- evidence_basis 取 community_discussion

## 边界与局限
- 未引用具体论文或 benchmark
- 退化程度因任务类型（recall vs reasoning）差异巨大
- 随模型迭代可能改善
