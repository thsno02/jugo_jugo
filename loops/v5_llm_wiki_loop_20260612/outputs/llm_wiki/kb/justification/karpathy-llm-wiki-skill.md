# Justification: karpathy-llm-wiki-skill

## 为什么提取这张卡

karpathy-llm-wiki 作为一个具体的工具实现，有其独立的身份：它是 Karpathy 思想的社区实现，打包为 Agent Skill 标准，有明确的三操作接口（Ingest/Query/Lint）和生产验证数据。这些实现细节超出了"LLM wiki 概念"本身。

## Evidence basis 选择: code_implementation

这是一个有 npm 安装命令、具体 API（三操作）、工具兼容性矩阵、以及生产统计数据的代码项目。

## 原子性判断

该卡聚焦于"karpathy-llm-wiki 这个具体实现是什么、做什么、怎么用"。虽然涉及多个方面（操作、安装、统计），但都围绕同一个工具实体展开，属于对一个 tool 的完整描述。
