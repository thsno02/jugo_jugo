# Justification: librarian-mcp-as-llm-wiki-productization

## 为什么值得建卡

Librarian 是目前已知唯一将 Karpathy LLM Wiki 概念完整产品化的开源工具，且选择了 MCP 作为集成协议。对于 llm_wiki 知识库而言，它是 LLM Wiki pattern 从理念到工程实现的关键实例。

## evidence_basis 选择: code_implementation

材料是一个完整 GitHub repo 的 README，描述的是已发布的可安装软件（Homebrew、预编译二进制、cargo install），属于代码实现级别的证据。

## 原子性检验

本卡聚焦于 Librarian 的整体定位与架构决策（产品化 LLM Wiki + 本地运行 + MCP 协议 + 独立二进制），不涉及具体机制细节（图遍历、auto-linking 各拆独立卡）。
