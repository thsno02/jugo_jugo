# Justification: query-as-contribution

## Extraction rationale
材料明确将 query 回写标记为"important insight"，是区别于传统 chat 模式的关键设计原则。与 ingest 并列但机制不同（用户探索 vs 外部来源），值得独立成卡。

## Evidence quality
- 材料中有明确 "The important insight" 标记
- 具体列举了可回写的内容类型
- 无 hedge

## Atomicity check
仅覆盖 query 回写这一设计原则。Query 的检索机制（使用 index.md）归入 index 相关卡片。
