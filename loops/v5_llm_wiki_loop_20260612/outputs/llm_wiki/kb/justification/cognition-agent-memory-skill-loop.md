# Justification: cognition-agent-memory-skill-loop

## 为什么产出此卡
材料核心内容之一是 Cognition 产品的四步 skill 循环工作流（Ask → Capture → Save → Retrieve），这是产品页面最详细展开的部分，占据页面主体。作为一个完整的 workflow 描述，适合独立成卡。

## Evidence basis 选择
选择 `practitioner_report`：这是产品团队对自身工作流的描述，属于实践者视角的报告，非经验证的研究结论。

## 原子性判断
四步法构成一个完整循环，拆开任何一步都无法独立表达该工作流的设计意图。作为整体保留。

## Hedge 使用
材料以产品宣传口吻陈述，未使用 hedge 语言，卡片据实记录。
