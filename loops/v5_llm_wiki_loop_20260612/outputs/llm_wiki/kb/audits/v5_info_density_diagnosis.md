# v5 信息密度根因诊断报告

日期: 2026-06-12
方法: 6 探针独立调查 + 交叉综合

---

## 判定

**v5 卡片信息确实贫乏，但贫乏的维度不是"字数少"而是"论证浅"。**

v5 字符量比 v4 多 56%，卡片总数多 45%（477 vs 328），覆盖广度无争议地优于 v4。问题在于: 每张卡的认知价值密度下降了——同样一个概念，v4 用 700 字给你"机制 + 反驳 + 替代方案 + 边界条件 + 元认知空白标注"，v5 用 1100 字给你"机制描述 + 子主题罗列 + 参数枚举"。前者读完能做判断，后者读完只能做检索。

---

## 一、根因排序（从最重要到最次要）

### 根因 1: Reframing 阶段丢失论证层次（贡献度 ~40%）

**证据**:
- Probe 3: 同源卡 body 压缩 44-73%（ARES -44%, LightMem -55%, RAGChecker -73%）
- Probe 6: v4 card-footnotes 建立多方张力关系（distinction footnotes 用完整句描述两卡区分），v5 card-footnotes 退化为简单指针
- Probe 1: card 互引数从 v4 平均 1.9 条降至 v5 平均 0.8 条（-58%）
- Probe 6: v4 `human-llm-role-division` 包含"正面描述 → HN 社区反驳 → 镜像补偿原则对照 → 门控机制"四层论证; v5 同源卡仅有"人类做 X、LLM 做 Y、理由是 Z"单层描述

**机制解释**: v5 reframing 将 v4 的整合型卡片拆为多张窄焦点卡。拆分本身是合理的 Zettelkasten 操作，但拆分时只保留了"是什么"维度，系统性丢弃了"为什么这样设计"、"什么条件下不成立"、"与替代方案的 tradeoff"。reframing prompt 虽然在 v5 扩展了 36 行（Probe 4），但新增内容（hedge 保留规则、evidence_basis 字段）面向形式合规，未面向论证深度。

### 根因 2: 追问深度过早终止（贡献度 ~30%）

**证据**:
- Probe 2: v5 卡片以 Phase 1-2 特征为主（机制描述、定位对比、定义+数据列举），Phase 3-4 特征（边界条件、隐含假设、内部张力）明显弱于 v4
- Probe 6: v4 `cross-session-continuity` 主动标注源材料空白（"材料未讨论哪些具体信息会在会话边界丢失"），v5 无此类批判性标注
- Probe 2: v5 有效源从 50 增至 63，每 wave 处理 ~16 源，单源分配的 agent 注意力被稀释

**机制解释**: v5 四波并行提取，每波处理约 16 个源。questioning loop 的五阶段设计不变（Probe 4 确认 skills 文件几乎 identical），但源数量增加 26% 导致每源可用的推理预算下降。Phase 2 末期的"信息递减启发式"（v5 新增的唯一一行: 长材料衰减启发式）可能过早触发 SATISFIED，跳过了 Phase 3（边界条件追问）和 Phase 4（隐含假设挖掘）。追问深度元数据（round/phase）未落盘，无法精确量化，但抽样定性证据一致指向此结论。

### 根因 3: 大材料固定产出窗口（贡献度 ~20%）

**证据**:
- Probe 5: 小材料 0.604 卡/KB vs 大 arxiv 0.062 卡/KB，提取率差 10 倍
- Probe 5: 无论 v4 还是 v5，单源 arxiv 产出被夹在 11-17 张卡，272KB 论文不比 152KB 论文多产多少
- Probe 3: RAGChecker v4 卡含完整三层指标体系（11 个子指标+设计动机），v5 仅保留 overall metrics 公式

**机制解释**: reader agent 对大材料存在隐式的产出天花板。这不是 v5 特有问题（v4 也存在），但 v5 的有效源中大 arxiv 占比更高（11/63 vs v4 的 8/50），因此天花板效应被放大。一篇 272KB 的 LongMemEval 论文理论上可支撑 30-40 张高密度卡，实际只产出 11 张——约 60% 的信息量未被提取。

### 根因 4: 引用网络稀疏化（贡献度 ~10%）

**证据**:
- Probe 1: src 引用从 v4 平均 4.2 条降至 v5 平均 2.5 条（-40%）
- Probe 1: card 互引从 v4 平均 1.9 条降至 v5 平均 0.8 条（-58%）
- Probe 6: v4 footnotes 标注至行号（L180、L159），v5 标注至段落（Design boundary P2）

**机制解释**: 引用网络稀疏化既是上述三个根因的结果（拆分卡片后互引断裂、追问不深无跨概念对比、大材料提取不足无法建立内部关联），也是一个独立的恶化因子——稀疏引用使得卡片变成孤岛，读者无法通过引用链重建论证上下文。v4 的 distinction footnotes（`[^dist-N]`）是独立的分析单元，每条用完整句解释两卡关系; v5 完全缺失此结构。

## 二、v4 vs v5 关键差异（导致信息密度下降的具体环节）

| 环节 | v4 | v5 | 影响 |
|------|------|------|------|
| 每源卡数 | 6.56 | 7.57 | v5 更多卡但单卡更薄 |
| body 字符 | 700 avg | 1094 avg | v5 膨胀 56% 但论证层次未增 |
| src footnotes | 4.2/卡 | 2.5/卡 | v5 单源事实堆叠，缺少多源交叉验证 |
| card footnotes | 1.9/卡 | 0.8/卡 | v5 概念间张力关系消失 |
| distinction footnotes | 存在 | 完全缺失 | v5 失去了"两卡如何区分"的元认知 |
| 论证结构 | 正面+反驳+替代+边界 | 描述+列举 | v5 从"判断型"退化为"检索型" |
| 材料空白标注 | 存在 | 缺失 | v5 不批判源材料局限性 |
| Phase 3-4 特征 | 显著 | 稀少 | v5 追问停在"是什么/怎么做" |

**一句话总结**: v5 用"广度+字数"换掉了"深度+结构"，产出从"可供决策的知识"退化为"可供检索的事实集合"。

## 三、修复建议

### A. 面向当前 v5 KB（可补救措施）

1. **Reframing 修补 pass**: 对 477 张卡执行二次 reframing，prompt 增加显式指令:
   - 每张卡必须包含至少一个"边界条件"或"此机制不成立的场景"
   - 如原始材料中存在替代方案/竞争设计，必须以 tradeoff 句式呈现
   - 恢复 distinction footnotes: 每条 `[^card-N]` 必须用完整句说明"本卡与该卡的区分点"
   - 目标: src footnotes >= 4/卡, card footnotes >= 2/卡

2. **大材料二次提取**: 对 11 篇大 arxiv（>150KB）执行针对性补提:
   - 明确指示: "论文中的消融实验、失败案例、局限性讨论、与相关工作的设计取舍对比"
   - 预期每篇补充 5-10 张卡，填补方法论细节和 negative results

3. **引用网络重建**: 全局扫描 477 张卡，用 governance 聚类结果驱动 card-footnote 补充:
   - 同 cluster 内的卡之间必须有至少一条 card-footnote 建立关系
   - 不同 cluster 但共享源的卡之间建立 distinction footnotes

### B. 面向 v6 管线改进

1. **Questioning loop 元数据落盘**: 卡片 frontmatter 新增 `origin_phase: N` 字段（N=1-5），事后可审计追问深度分布。目标: Phase 3-4 来源的卡片占比 >= 30%。

2. **材料规模感知的产出目标**: reader agent 收到源材料时，先估算 KB 量级，设定最低产出目标:
   - <50KB: 8-15 卡
   - 50-150KB: 15-25 卡
   - >150KB: 25-40 卡
   - 这打破固定产出窗口

3. **Reframing prompt 增加论证层次检查**: 在 reframing skill 中增加 hard constraint:
   - body 中必须存在至少一个反驳/限制/tradeoff 句（含 however/但/除非/代价 等信号词）
   - 否则自动触发 Phase 3 追问补充

4. **并行 wave 负载均衡**: 根据源材料大小分配 wave，而非均分源数量:
   - 大材料（>150KB）单独分配给一个 agent，保证充足推理预算
   - 小材料可聚合在一个 wave 中

5. **Distinction footnotes 作为 schema 硬约束**: 在 reframing 输出 schema 中将 `distinctions` 设为 required 字段（至少 1 条），格式为: `"与 [card-slug] 的区分: [完整句]"`

6. **SATISFIED 触发条件收紧**: questioning loop 的信息递减启发式增加门槛:
   - 必须至少完成 Phase 3（边界条件追问）后才允许触发 SATISFIED
   - Phase 4（隐含假设）可选，但 Phase 3 为 hard gate

## 四、量化目标

### 信息密度合格线（v5 修补后 / v6 目标）

| 指标 | v5 现状 | 修补目标 | v6 目标 | 理由 |
|------|---------|----------|---------|------|
| body 字符数 | 1094 avg | 900-1100 | 800-1000 | 字数不需增加，需要的是结构改善 |
| src footnotes/卡 | 2.5 | >= 4.0 | >= 4.5 | 恢复多源交叉验证 |
| card footnotes/卡 | 0.8 | >= 1.5 | >= 2.0 | 重建概念网络 |
| distinction footnotes/卡 | 0 | >= 0.5 | >= 1.0 | 新增结构，强制概念区分 |
| 含"边界条件"句的卡片比例 | ~15%(估) | >= 40% | >= 50% | Phase 3 追问成果可见性 |
| 大材料(>150KB)产卡数 | 11-17 | 20-30 | 25-40 | 打破固定窗口 |
| Phase 3-4 来源卡比例 | 未知(估<20%) | -- | >= 30% | v6 落盘后可审计 |

### 综合密度评分公式（建议 v6 采用）

```
density_score = (src_footnotes * 0.3) + (card_footnotes * 0.25) + (has_boundary_condition * 0.25) + (has_tradeoff_or_alternative * 0.2)
```

合格线: density_score >= 1.5（满分约 3.5）

## 五、最终判断

v5 的问题不是"做得差"，而是"做得浅"。它在广度维度（477 卡、63 源、+45% 总量）显著优于 v4，但在深度维度（论证层次、引用网络、批判性标注）全面退步。这不是单一原因造成的，而是四个因素叠加:

1. Reframing 拆分时丢弃论证结构（主因）
2. Questioning 追问过早满足（次因）
3. 大材料产出天花板（结构性限制）
4. 引用网络稀疏化（恶化因子）

如果只改一件事: **改 reframing prompt，强制保留论证层次和 distinction footnotes**。这是 ROI 最高的单点修复。
