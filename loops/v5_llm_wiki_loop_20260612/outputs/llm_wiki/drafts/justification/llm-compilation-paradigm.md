# Justification: llm-compilation-paradigm

## 为什么产出此卡
材料开篇即声明核心理念："the correct way to use LLMs is not Q&A, it's compilation"，这是整个仓库的理论基础，构成独立原子概念。

## 证据强度
- 明确引用 Andrej Karpathy 的 gist 作为 baseline
- README 通篇围绕此范式展开工具设计
- evidence_basis 取 code_implementation：仓库提供完整脚本将范式落地

## 边界决策
- 与五条规则分离：规则是范式的操作化细则，范式本身是更高抽象
- 与三层架构分离：架构是范式的物理表达，范式是认知层面的主张
