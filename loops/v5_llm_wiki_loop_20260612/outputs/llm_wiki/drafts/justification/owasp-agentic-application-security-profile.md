# Justification: owasp-agentic-application-security-profile

## 为何成卡

材料明确给出了 agentic application 在安全语境下的特征描述（plan / act / make decisions across complex workflows），这构成一个独立的概念定义知识点，区别于框架整体定位。

## Evidence basis 选择

选择 `normative_standard`：该定义出自 OWASP 官方发布的规范性文档，具有标准制定机构的权威性。

## 拆卡决策

从框架概览卡中拆出：框架定位回答"这是什么、谁做的、为谁服务"，本卡回答"保护对象的技术特征是什么"。两者各自原子化。
