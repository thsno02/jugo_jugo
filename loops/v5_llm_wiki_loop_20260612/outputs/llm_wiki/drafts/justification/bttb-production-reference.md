# Justification: bttb-production-reference

## 为什么产出此卡
BTTB 是材料的主体对象，有独立的项目身份、规模数据、许可模型和工作流描述，不等同于抽象的 LLM Wiki 模式本身，需单独建卡记录这一具体实例。

## 证据质量
- evidence_basis: practitioner_report — 项目作者对自身产出的描述
- 数字 (27 sources, 120+ pages, 1400+ links) 可通过克隆 repo 验证

## Reframing 决策
- 将散布各段的项目信息聚合为单卡
- card_type 定为 project-instance 以区别于 architecture-pattern
- 保留 repo URL 和许可信息供后续查证
