内生知识与 RAG：机制、局限与前沿案例

路径 Path
解释 Explanation
案例 Case
1
模型内生知识 Parametric Knowledge

依赖模型参数中编码的知识

  • 机制知识在预训练和微调阶段写入模型权重，推理时直接从参数中提取
  • 优势响应快，无需外部检索或额外基础设施
  • 问题知识不可控，容易受输入干扰产生幻觉，无法提供可追溯的答案
快速响应 不可控 不可追溯 易幻觉

大多数裸模型调用属于此类，无专用方案名称。

2
检索增强生成 RAG

通过外部语料库约束回答

  • 机制查询时从外部语料库检索相关片段，拼接进 prompt 生成回答
  • 优势可建立来源约束，适合接入企业文档、研究资料和业务数据
  • 问题只解决查询时召回，缺乏知识回流（write-back）和治理（governance）机制
  • 局限语料库往往静态，知识难以持续生长
可追溯 来源约束 静态语料 无回流机制

Graphify / 图化

将 code、docs、PDF、images、videos 等材料转为图文件，再基于图结构查询项目知识。增强材料的结构化程度与可检索性。

GraphRAG

在索引阶段构建图谱和多层摘要，处理长文本、多跳关系和复杂语料理解。微软提出的增强 RAG 范式。
