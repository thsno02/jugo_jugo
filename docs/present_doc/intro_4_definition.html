LLM Wiki 的定义与核心属性

LLM Wiki 是一个由大语言模型和智能体持续维护的知识卡片系统。每个知识卡片是人类可读、智能体可操作、来源可追溯的知识对象；卡片之间通过链接、引用、标签、实体关系、主题关系和时间关系形成轻量知识图；系统通过持续的提取、定界、去重、融合、链接、审核和提升，把原始文档逐步转化为可复用的知识库。
设计重点
核心属性
1 知识卡片是默认最小单元

"最小"是建模原则，不是强制切分。每张卡片应是可被人或智能体直接完整消费的信息簇：明确主题、清楚边界、可读正文、来源支撑、可维护状态。

来源锚定（source-grounded）
每个知识可追溯到原始资料，关键判断有来源、证据和适用上下文，避免退化为不可验证的生成文本
结构约束（schema-constrained）
知识对象遵守稳定结构；显性层是卡片供阅读，隐性层是来源证据、比较记录、版本记录和审核记录供治理
2 图结构是组织方式之一

卡片为节点，引用、主题、实体、相似、冲突、增量关系为边。图帮助导航、检索和分析，但知识的主要承载物仍然是可读、可引用、可追溯的卡片。

关系可链接（linkable / graphable）
通过引用、主题、实体、相似、冲突、增量等关系形成网络；图提供组织和查询视图，卡片承载知识内容
3 核心能力是知识治理

管理知识从草稿（draft）→ 候选（candidate）→ 稳定（stable）的状态变化，也管理来源、边界、冲突、版本、审核和回流。

版本可审计（versionable / auditable）
知识有草稿、候选、稳定、废弃等状态，记录变更、审核和提升过程，让知识演化可被检查
智能体可操作（agent-operable）
智能体可创建、更新、拆分、合并、补充来源、标记冲突、执行检查，并把有价值回答写回知识库
