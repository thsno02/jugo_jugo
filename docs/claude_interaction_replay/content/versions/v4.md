# v4：用提问循环独立地从 0 到 1

## 版本核心

v4 不是在 v3 KB 上继续追加，而是一次独立的 0→1 实验。questioner 持续提出材料仍未回答的问题，reader 回到原文寻找证据，reframing 把回答变成知识卡，reviewer 与 FSJS 负责验收。

## 相对 v3 的优化

- 从 pipeline-first 改为 question-driven discovery。
- 不继承 v3 卡片，减少既有知识图对发现过程的污染。
- 引入 typed footnotes，区分 source、card、distinction 和 URL。
- 用 justification journal 保存“为什么这张卡成立”的可读判断。
- 采用 grep-only governance 和 FSJS，先机械过滤，再对 suspect 做语义判断。
- 将材料穷尽和卡片关系治理分成独立阶段。

## 关键决策

知识发现阶段优先忠实穷尽材料，不把已有 taxonomy 当成问题清单。卡片之间的连接可以 best-effort，但来源引用必须准确；comparison / distinction card 允许作为有意的单向 sink。

## 实际动作

先用小材料迭代 questioning、reader、reframing 和 reviewer，再扩展到完整材料池；随后执行 cross-link、拆卡、缺失卡补充、全量审计和下一轮准备。
