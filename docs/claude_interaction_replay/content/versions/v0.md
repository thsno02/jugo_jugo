# v0：先证明知识生产机制能够运转

## 版本核心

v0 不是最终的 LLM Wiki，而是一个 filesystem-backed 的知识库生产机制实验。它验证版本包、来源追踪、引用图、反向链接、影响队列、动态检索记录和恢复控制面能否组成一个可审计闭环。

## 触发问题

最初要解决的是：如果 LLM 持续更新一个知识库，怎样让每次变化都可追踪、可验证、可恢复，而不是反复覆盖一批 Markdown 文件？

## 关键决策

把知识节点、采用视图、生成图和控制状态都保存为文件，并为 major change 构建影响传播队列。动态检索即使失败也要留下记录，不能把失败来源伪装成证据。

## 实际动作

构建 7 个 adopted nodes、7 个 KB views、35 条 citation edges，并模拟一个未采用的 2.0 candidate 及 4 个开放影响项。运行结构校验、引用解析、影响计算和状态汇总。

## 失败与纠偏

机制验证成功，但生产机制本身被误当成 topic KB 内容。结果回答了“怎样建知识库”，没有真正构建关于 LLM Wiki 的知识库。

## 如何触发 v1

topic 错位迫使下一轮重置内容方向：保留机制，改为直接建设 LLM Wiki 的主题知识结构。
