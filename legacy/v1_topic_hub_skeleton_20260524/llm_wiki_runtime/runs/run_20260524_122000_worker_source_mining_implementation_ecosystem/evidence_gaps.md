# Evidence Gaps

## Non-Blocking for Bounded v1

- Package downloads are not preserved locally.
- Plugin install counts and active users are not preserved locally.
- GitHub traffic/clones, contributors, release history, issue/PR outcomes, and dependency/security posture are not mined.
- Reddit/community reception captures are blocked or not usable for substantive claims.
- README and project pages are mostly author self-description.
- Directory/plugin pages are not independent quality evidence.
- Long-document, multimodal, enterprise, and governance claims vary by implementation and should not be generalized.

## Blocking Only for Broader Claims

The above gaps block a mature adoption/maturity/quality/enterprise-readiness node. They do not block a first-version descriptive implementation landscape node if the node stays bounded to implementation families, local metadata signals, and evidence-quality warnings.
